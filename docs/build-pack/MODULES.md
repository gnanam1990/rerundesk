# RerunDesk · module index

These are dependency-ordered work units. Once a contract is agreed, UI, adapter and test contributors may proceed on fixtures matching that contract and integrate against its real implementation before acceptance.

1. [M01 · Recipe admission and provenance](prompts/M01.md) — Implement licensed input intake, image digest verification, fixed command catalog and content-addressed recipe manifests.
2. [M02 · Claims and comparison contract](prompts/M02.md) — Freeze evaluator, units, seed set, tolerance, baseline, hardware constraints and aggregation before procurement.
3. [M03 · Worker enrollment and purchase](prompts/M03.md) — Bind organization evidence, capacity offer, expiry and maximum spend. Reconcile paid reservations by merchant order identity.
4. [M04 · Leased isolated execution](prompts/M04.md) — Issue worker-scoped fenced leases, mount known inputs read-only, disable egress and pin the CPU execution profile.
5. [M05 · Artifact reception and verification](prompts/M05.md) — Collect outputs, runtime metadata, output cardinality, logs and hashes inside a bounded bundle. Recompute digests and seal the manifest.
6. [M06 · Deterministic comparison](prompts/M06.md) — Implement the pinned metric on worker outputs. Distinguish divergence from missing evidence, bad seed, metric mismatch or incompatible hardware.
7. [M07 · Report, settlement and repeatability](prompts/M07.md) — Ship run timeline, outcome explanation, independent-operator evidence, exact reproduction manifest and separate cost history.
